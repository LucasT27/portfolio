Google Sheets · Apps Script

Fausto Motos

Herramienta para gestionar presupuestos y servicios de mantenimiento de un taller de motos. Centraliza cálculos, datos de cada trabajo y controles de revisión dentro de Google Sheets.

En desarrollo avanzado
  • Google Sheets
  • Apps Script
  • JavaScript
  • HTML / CSS
  • Node Test Runner
  • GitHub Actions

Arquitectura

  1. 01 · Interfaz

    Formularios en Sheets

    Menús, desplegables y fórmulas permiten cargar presupuestos y servicios sin salir del libro.

  2. 02 · Reglas

    Apps Script

    Módulos de validación, cálculos, numeración y persistencia. Los bloqueos coordinan las reservas de números.

  3. 03 · Persistencia

    Tablas del libro

    Registros de motos, presupuestos, ítems, servicios y checklist. Se conservan los datos y precios de cada trabajo.

Qué se hizo

  • Presupuestos con estados, vigencia, seña, saldo y recálculo antes del guardado.
  • Servicios con precios configurables, adicionales y un checklist de 26 controles.
  • Módulos de documentos, historial y recuperación, con pruebas locales y controles automáticos en GitHub Actions.

Decisión técnica

Conservar una copia de los datos y precios aplicados en cada presupuesto o servicio. Así, un cambio posterior de configuración no modifica el contenido histórico del trabajo.
