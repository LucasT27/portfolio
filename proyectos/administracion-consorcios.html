Administración de Consorcios

Sistema para seguir una gestión desde el reporte inicial hasta su resolución. Reúne casos, tareas, proveedores, mantenimiento y documentos, conservando el contexto y la historia de cada actuación.

Piloto publicado · En evolución Acceso autenticado · Código privado
  • React / TypeScript
  • Vite
  • Supabase
  • PostgreSQL
  • Netlify
  • GitHub Actions

Arquitectura

  1. 01 · Interfaz

    SPA con React

    Pantallas organizadas por módulos, rutas protegidas y carga diferida. El frontend se publica en Netlify.

  2. 02 · Operaciones

    Supabase Auth y RPC

    Autenticación y funciones de base de datos para validar y ejecutar las operaciones de negocio.

  3. 03 · Datos y archivos

    PostgreSQL y Storage

    Permisos por rol, aislamiento por administración y documentos privados con descarga autorizada.

Qué se hizo

  • Reportes, casos, tareas y agenda con responsables, vencimientos, resultados e historial.
  • Unidades, proveedores, mantenimiento preventivo y documentación versionada; seguimiento de obligaciones, seguros y asambleas.
  • Búsqueda contextual, pruebas de interfaz y base de datos, y controles de publicación mediante GitHub Actions.

Decisión técnica

Usar la administración como frontera de acceso. Las reglas de autorización se aplican en la base de datos, y las transiciones conservan el historial para reconstruir quién intervino y qué se resolvió.

El alcance es la gestión operativa y el mantenimiento. La liquidación de expensas y la contabilidad quedan fuera de este proyecto.
