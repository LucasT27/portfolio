ERP · Escritorio Windows

Hojas de Vida ERP

Aplicación Windows para centralizar la operación de un dispensario de cannabis medicinal: ventas, stock, caja, compras y entregas. Los datos se conservan en una base local.

Desarrollo terminado
  • Electron
  • React / TypeScript
  • Java 21
  • Spring Boot
  • PostgreSQL
  • Flyway

Arquitectura

  1. 01 · Interfaz

    React dentro de Electron

    Pantallas de gestión en una aplicación instalable. Electron coordina el inicio y cierre de los procesos locales.

  2. 02 · Lógica de negocio

    API con Spring Boot

    Java concentra las operaciones, validaciones y permisos que utiliza la interfaz.

  3. 03 · Datos

    PostgreSQL local

    Persistencia en Windows, migraciones con Flyway y respaldos para conservar la información entre versiones.

Qué se hizo

  • Gestión de clientes, ventas, pagos, stock por lotes, caja, compras y entregas.
  • Usuarios y permisos, auditoría de operaciones y reportes exportables a PDF y Excel.
  • Empaquetado para Windows y un proceso de actualización con respaldo verificado y controles de integridad.

Decisión técnica

Integrar la interfaz, el backend y la base de datos en una experiencia de escritorio. La persistencia se mantiene separada de los archivos del programa para acompañar las actualizaciones sin reemplazar los datos del usuario.
