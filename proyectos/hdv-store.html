E-commerce · Serverless

HDV Store

Tienda online que reúne productos en stock e importaciones a pedido. Permite navegar el catálogo, armar un carrito, pagar con Mercado Pago y administrar productos y pedidos.

En producción · Evolución activa
  • JavaScript vanilla
  • Node.js
  • Netlify Functions
  • Supabase
  • PostgreSQL
  • Mercado Pago

Arquitectura

  1. 01 · Interfaz

    HTML, CSS y JavaScript

    Páginas estáticas para catálogo, carrito, cuenta y checkout, con módulos compartidos y diseño adaptable a móviles.

  2. 02 · Backend

    Netlify Functions

    Funciones serverless para pagos, pedidos e integraciones. Mercado Pago comunica cambios mediante webhooks.

  3. 03 · Datos e identidad

    Supabase y PostgreSQL

    Autenticación de compradores y operaciones SQL transaccionales para pedidos, reservas y movimientos de inventario.

Qué se hizo

  • Catálogo con búsqueda y filtros, carrito persistente, cuentas de usuario y checkout con Mercado Pago.
  • Panel de productos y pedidos, control de inventario y archivado administrativo sin eliminar los registros comerciales.
  • Reservas de stock, validación de pagos y operaciones idempotentes para manejar reintentos y notificaciones repetidas.

Decisión técnica

Separar el estado del pago de la preparación y entrega del pedido. Las transiciones comerciales se resuelven en la base de datos para coordinar pagos e inventario y evitar aplicar dos veces una misma operación.
