E-commerce · Serverless

HDV Store

Tienda online para productos en stock e importaciones a pedido, con pagos integrados mediante Mercado Pago y gestión de envíos con Correo Argentino. Reúne catálogo, carrito, cuentas de usuario y administración de productos y pedidos.

En producción · Evolución activa
  • JavaScript vanilla
  • Node.js
  • Netlify Functions
  • Supabase
  • PostgreSQL
  • Mercado Pago
  • Correo Argentino

Arquitectura

  1. 01 · Interfaz

    HTML, CSS y JavaScript

    Páginas estáticas para catálogo, carrito, cuenta y checkout, con módulos compartidos y diseño adaptable a móviles.

  2. 02 · Backend

    Netlify Functions

    Funciones serverless para pedidos e integraciones con Mercado Pago y Correo Argentino. Los cambios de pago se reciben mediante webhooks.

  3. 03 · Datos e identidad

    Supabase y PostgreSQL

    Autenticación de compradores y operaciones SQL transaccionales para pedidos, reservas y movimientos de inventario.

Qué se hizo

  • Catálogo con búsqueda y filtros, carrito persistente, cuentas de usuario y panel de productos y pedidos.
  • Mercado Pago: checkout online, validación de pagos y recepción de notificaciones mediante webhooks.
  • Correo Argentino: cotización de envíos, selección de sucursales y creación de envíos desde el administrador.
  • Reservas de stock, archivado de pedidos y operaciones idempotentes para manejar reintentos y notificaciones repetidas.

Decisión técnica

Separar el estado del pago de la preparación y entrega del pedido. Las transiciones comerciales se resuelven en la base de datos para coordinar pagos e inventario y evitar aplicar dos veces una misma operación.
